# Pythagoras Project - CIS releases

Published userscript and release notes for Pythagoras Project - CIS.

Install and receive updates through [GreasyFork](https://greasyfork.org/en/scripts/580933-pythagoras-project-cis).

This repository is the automatic GreasyFork source mirror. Each release commit contains only that version's changelog; full notes are in `RELEASE_NOTES.md`. Development and private application files live separately.
